# Scaled Space Model

A pinch-to-zoom scale model of the solar system for your phone, live at **[b-e-spaceday.com](https://b-e-spaceday.com)**.

Every object is drawn at its true model size, with the Sun-to-Pluto distance set to 500 ft by default (changeable in settings). At ×1, what you see on screen is the actual size of that object in the model. Pinch to zoom in until it's visible.

## What's here

- `index.html`: the whole app (one page, no build step)
- `*.jpg`, `saturn_ring.png`: planet surface maps
- `icon-*.png`, `manifest.webmanifest`: home-screen icon and app settings
- `CNAME`: connects the custom domain. Don't delete it.

Hosted with GitHub Pages from the `main` branch.
